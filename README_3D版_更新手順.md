# Halo Friends v0.4.0 3D版（Minecraft Forge 1.20.1）

## 改善内容

これまでの v0.3.0 は、透明画像をカメラに向けた1枚の板に貼っていたため、立体ではありませんでした。
今回の v0.4.0 は、各画像の輪郭をポリゴン化し、厚みを付けてあります。

- シロコ：青い二重の輪を、内側の穴もある厚み付き形状に変換
- ヒナ：黒紫の輪・棘・左右の飾りを立体化
- ワカモ：赤い紋章の外形と内側の図柄を立体化
- 表面と裏面、さらに**側面**を描画
- カメラ追従を廃止し、プレイヤー頭部の回転に追従
- 明るく見える全輝度描画。**周囲を照らす動的ライトではありません**
- Forge 1.20.1用（NeoForgeではない）

## GitHubへの反映方法（推奨）

1. すでにある `HaloFriends` リポジトリの Code ページを開く。
2. このZIPを解凍して、**中の全ファイルとフォルダ**を GitHub にアップロードする。
   - `src/main/java/...` 以下の階層を壊さないこと。
   - `.github/workflows/build-jar.yml` も更新すること（古い版が残ると旧版のJAR名になる）。
   - 既存ファイルと同じ名前のものは上書きする。
   - ZIP自体をアップロードしてもビルドされません。
3. `Commit changes` で保存。
4. Actions → Build Halo Friends 1.20.1 Forge JAR → 新しい実行の Summary を開く。
5. Artifacts → HaloFriends-Forge-1.20.1-v0.4.0-JAR をダウンロードしてZIPを解凍。
6. 旧版 `HaloFriends-1.20.1-forge-0.3.0.jar` を **modsから削除**し、新しい `HaloFriends-1.20.1-forge-0.4.0.jar` を入れる。
   **両方を同時に入れないこと。**

## 読み込みテスト

Forge 1.20.1を起動して以下を実行：

```
/give @s halo_friends:shiroko_halo
/give @s halo_friends:hina_halo
/give @s halo_friends:wakamo_halo
```

それぞれ頭スロットで装備し、F5で三人称視点にして、視点をぐるっと回す。
横方向から厚みが見え、常にカメラを向く板にならないことを確かめる。
