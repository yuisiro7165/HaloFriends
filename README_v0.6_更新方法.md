# Halo Friends v0.6.0 — 正面から見える薄型3Dヘイロー

Minecraft Java 1.20.1 / Forge 47.4.28 向け。シロコ、ヒナ、ワカモの3種類を収録。

## なぜ v0.5 は平たく見えた？
前版はモデルを 48～68度傾けていたため、第三者視点の正面や背面から見ると、輪郭が横一線に潰れていました。
**厚みが小さいこと自体より、角度が大きすぎたことが主原因**です。

## v0.6 の修正
| キャラ | v0.5の傾き | v0.6の傾き | 横幅 | 高さ | 厚み | 中心高さ（モデル座標） |
|---|---:|---:|---:|---:|---:|---:|
| シロコ | 68° | 18° | 1.03 | 0.76 | 0.018 | -0.96 |
| ヒナ | 65° | 14° | 1.30 | 0.85 | 0.022 | -1.01 |
| ワカモ | 48° | 11° | 0.96 | 0.98 | 0.020 | -1.07 |

モデルはプレイヤーの頭に固定。カメラを向く板（ビルボード）ではなく、**正面・背面・ごく薄い側面の3Dメッシュ**です。
送付された画像の模様を維持し、カラーの明度を微調整。輪郭の外側の光のにじみをゲーム中でも見えやすい幅に改善しました。
ただしシェーダーのBloomや周囲を照らす動的光源は実装していません。

## 更新方法（GitHubのWeb画面）
1. `HaloFriends_v0.6.0_game_style_update.zip` を解凍する。
2. GitHub → `HaloFriends` → `Code` → `Add file` → `Upload files` を開く。
3. **ZIPではなく解凍した中身**をフォルダ構造を維持してアップロード（既存ファイルを更新）。
4. `Commit changes` → `Actions` → 最新のビルドへ進む。
5. ビルド成功後、Artifacts欄の `HaloFriends-Forge-1.20.1-v0.6.0-JAR` をクリック。
6. ZIPから `HaloFriends-1.20.1-forge-0.6.0.jar` を取り出し、Minecraft Forge 1.20.1 の `mods` フォルダに入れる。
7. **v0.3、v0.4、v0.5 の旧JARは外す**（同じMOD IDが重複すると起動に失敗します）。

## 確認方法
- シロコ・ヒナ・ワカモの各ヘイローを装備し、F5で正面と背面から模様の見え方を確認。
- 横・斜めから見たときに僅かな厚みがあるか確認。
- 昼・夜で輪郭の見やすさを確認。
- サーバーと各プレイヤー側に同じバージョンを導入して確認。

アイテムコマンド：
```
/give @s halo_friends:shiroko_halo
/give @s halo_friends:hina_halo
/give @s halo_friends:wakamo_halo
```

## 現段階の制限
この環境ではForgeGradleの依存関係を取得できないため、**Forgeのコンパイル／実ゲーム表示は未検証**。
ソースと画像・3Dメッシュの整合性検査まで実施しています。
3種の見え方は実際のゲーム内で再評価してください。
